개인정보처리방침

이누미디어 현황판 · 시행일 2026년 11월 12일

이누미디어 현황판은 이누미디어 ENG사업부의 이동 현황, 업무 기록 및 법인카드·영수증 정산을 관리하는 사내 업무용 웹앱입니다. 이 방침은 앱에서 처리하는 정보와 그 이용 방식을 안내합니다. 실제 처리 항목은 사용자가 이용한 기능과 관리자 설정에 따라 달라집니다.

이 공개 안내 사이트는 서비스 설명과 정책 문서만 제공합니다. 개인정보 입력·로그인·영수증 업로드 기능과 Google OAuth 승인·AI 전송 기능은 이 안내 사이트에 없습니다. 업무 입력과 연결 기능은 사내에서 별도로 안내하는 실제 현황판 앱에서 이루어집니다.

이 안내 사이트는 GitHub Pages로 호스팅됩니다. 호스팅 제공자인 GitHub는 로그인 여부와 관계없이 보안 목적으로 방문자의 IP 주소를 기록·저장합니다. 해당 접속 정보의 처리에는 GitHub 개인정보처리방침이 적용됩니다.

1. 운영 주체와 문의

운영 주체는 이누미디어 ENG사업부 현황판 관리자입니다. 개인정보 열람·정정·삭제, 계정 접근, 공유 링크와 관련된 문의는 사내 연락망 또는 앱의 Google 동의 화면에 표시된 사용자 지원 이메일로 접수합니다.

2. 처리하는 정보와 목적

사용 기능별 정보와 이용 목적
구분처리 항목과 목적

이동·업무 기록이동 상태, 사용자가 입력하거나 선택한 목적지, 복귀 예정 시각, 업무 메모와 작업 기록을 사내 현황 공유 및 업무 조율에 사용합니다.
카드·영수증 정산법인카드 대여·반납 내역, 사용자, 영수증 이미지, 결제 일시·금액·가맹점·내용·현장 등 입력하거나 추출한 내역을 사용 기록과 정산 자료 작성에 사용합니다.

이동시간 조회는 사용자가 선택한 출발지와 도착지의 주소·좌표를 이용합니다. 이 설명은 사용자가 입력·선택한 장소에 대한 것이며, 기기의 실시간 위치를 지속적으로 추적하는 기능을 뜻하지 않습니다.

3. Google 접근 권한의 사용

Google Drive
영수증 파일 업로드·조회, 정산 파일과 내보내기 파일 생성·관리, 관리자가 요청한 업데이트 코드 파일 읽기에 사용합니다.
Google Sheets
정산 시트와 업무 이력 작성, 기존 기록 조회, 월별 정산 및 엑셀 생성에 사용합니다.
외부 서비스 연결
설정된 Notion 연결, 사용자가 선택한 영수증 AI 읽기, 장소 검색 및 이동시간 조회 요청에 사용합니다.
Apps Script 프로젝트·배포 관리
관리자가 실행한 현황판 코드 업데이트와 배포 관리에 사용합니다.
예약 실행
관리자가 설정한 일정 동기화·상태 관리 등 정기 작업을 수행하는 데 사용합니다.

Google API에서 받은 사용자 데이터는 이 방침에 기재된 현황 공유, 업무 기록, 영수증 처리와 정산 기능을 제공하기 위해 사용합니다. 앱 운영자는 이를 판매하거나 광고 타기팅, 범용 AI 모델 학습을 위한 데이터셋으로 사용하지 않습니다. Google API에서 받은 정보의 이용 및 다른 앱으로의 전송은 Google API Services User Data Policy의 제한적 사용(Limited Use) 요구사항을 따릅니다.

4. 저장 위치와 접근·공유

  • 업무 상태와 설정, 일부 기록은 Google Apps Script의 Script Properties에 저장됩니다. 영수증 파일과 정산 자료는 연결된 Google Drive 및 Google Sheets에 저장됩니다.
  • 로그인 유지·화면 설정·임시 입력·사진 초안 등의 일부 정보는 사용 중인 기기의 브라우저 저장소에 저장됩니다.
  • 앱의 업무 기록은 관리자와 업무상 허용된 사용자에게 제공됩니다. Google 파일의 실제 접근 범위는 해당 파일·폴더의 공유 설정에도 영향을 받습니다.
  • 현재 앱은 영수증 사진과 일부 내보내기 파일을 링크를 아는 사용자가 조회할 수 있는 설정으로 저장합니다. 해당 링크를 전달받은 사람은 파일을 볼 수 있으므로, 업무상 허용된 사람에게만 전달해야 합니다. 공유 설정 조정 또는 삭제는 관리자에게 요청할 수 있습니다.

5. 외부 서비스에 전달하는 정보

연결한 기능을 사용하면 그 기능의 처리에 필요한 데이터가 다음 서비스로 전달될 수 있습니다. 연결하지 않은 기능에 대해 해당 서비스를 사용한다고 뜻하지는 않습니다.

영수증 사진 AI 읽기 — Google Gemini 또는 Anthropic Claude
사용자가 사진 읽기 기능을 실행하면 선택한 영수증 이미지와 읽기 요청이 관리자가 설정한 제공사의 API로 전달됩니다. 앱은 응답에서 결제 내역을 추출해 입력을 돕습니다. 외부 AI 제공사의 데이터 처리·보관에는 해당 제공사의 API 정책이 적용되며, 자동 추출 결과는 사용자가 확인·수정해야 합니다.
Notion
연결된 사내 업무 문서에서 일정과 업무 내용을 읽습니다. 사용자가 업무일지 입력을 명시적으로 요청하면 해당 업무 내용을 연결된 문서로 보냅니다.
카카오 장소 검색·이동시간 조회
사용자가 입력한 장소 검색어, 선택한 출발지·도착지 주소 또는 좌표, 조회에 필요한 출발 시각을 카카오 서비스로 전달해 경로와 소요시간을 확인합니다.

각 서비스의 개인정보 및 데이터 처리에 관한 최신 내용은 해당 제공사의 공식 안내에서 확인할 수 있습니다: Google Gemini API, Anthropic, Notion, Kakao Developers.

6. 보관과 삭제

업무 기록과 정산 자료는 해당 업무·정산 목적 및 적용되는 관계 법령상 보관에 필요한 기간 동안, 또는 관리자가 삭제할 때까지 보관합니다. 모든 자료에 공통으로 적용되는 고정 기간의 자동 삭제 기능을 제공한다고 보장하지 않습니다.

열람·정정·삭제가 필요하면 관리자가 대상 자료와 요청자의 권한을 확인해 처리합니다. 업무 또는 법령상 보관이 필요한 자료는 삭제가 제한될 수 있으며, 관련 사유를 안내합니다. 브라우저에 남은 임시 입력과 사진 초안은 해당 기기의 사이트 데이터 삭제로 지워질 수 있으므로, 보관이 필요한 자료는 먼저 정상 저장 여부를 확인해야 합니다.

7. Google 권한 철회와 이용 중단

Google 계정의 연결 관리에서 앱 접근 권한을 철회할 수 있습니다. 권한을 철회하면 연결된 기능의 이용이 제한될 수 있습니다. 권한 철회는 이미 저장된 업무 기록·영수증 파일의 자동 삭제와 별개입니다. 저장 자료의 삭제는 관리자에게 별도로 요청해 주세요.

8. 보호 조치와 방침 변경

앱은 등록 사용자와 기능별 업무 권한을 확인하며, 외부 서비스 키 등 연결 설정은 서버 측에서 관리합니다. 사용자는 로그인 정보와 공유 링크를 관리하고, 공용 기기 이용 후 저장된 로그인·초안 정보를 확인해야 합니다.

데이터 처리 방식이나 연결 서비스가 바뀌면 이 페이지의 방침과 시행일을 갱신하고, 필요한 변경사항은 사내 이용자에게 안내합니다.
